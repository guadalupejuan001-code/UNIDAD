# BEST final del control: pesos heredados

BEST permanece en el paso cero. Sus pesos, configuración y tokenizador coinciden
con el padre SFT072 BEST4.096. Su exposición nueva CONTROL es cero, aunque el padre
ya tenía entrenamiento propio previo.

[artifact-reference.json](artifact-reference.json) identifica el artefacto
completo existente mediante `artifactDirectory`. Este directorio no se carga
directamente con el motor. El [manifiesto final](manifest.final-selection.json)
preserva exactamente los metadatos de selección CONTROL sin alterar al padre ni
duplicar sus pesos.

La [entrega final](../../../../docs/learning-repair-20261013/natural-latam-v4-control-final-delivery.md)
distingue este BEST heredado del LAST realmente entrenado en 4.096 pasos.
No se acredita aceptación conversacional.
